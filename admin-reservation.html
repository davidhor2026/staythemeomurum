예약 신청 안내

전화·일반 문자 상담 후 예약을 원하는 고객에게 신청 링크를 보내는 안내 페이지입니다.

이용 방법

  1. 상담한 객실과 입주 희망일을 선택합니다. (선택하지 않으면 고객이 직접 입력합니다.)
  2. 안내 문자 복사를 눌러 고객에게 문자 또는 카카오톡으로 전달합니다.
  3. 고객이 신청서를 작성하고 휴대전화 문자 앱에서 전송하면 신청 내용을 확인합니다.
  4. 신청 내용을 검토한 뒤 계약금 계좌를 개별 안내하고, 입금 확인 후 예약을 확정합니다.

이 페이지는 일반 홈페이지 메뉴에 표시되지 않습니다. 주소를 즐겨찾기에 저장해 이용하세요. 다만 주소를 아는 사람은 접속할 수 있으므로 비밀번호로 보호되는 관리자 시스템은 아닙니다.

고객에게 보낼 예약 신청 링크

예약 확정 안내

예약 신청 문자 접수만으로 객실이 확보되거나 예약이 확정되지는 않습니다. 객실 및 입주기간 확인 후 원장님이 계좌를 안내하고 계약금 입금이 확인되면 예약이 확정됩니다.

고객의 신청 내용은 홈페이지에 자동 저장되지 않으며, 고객이 문자 앱에서 실제 전송 버튼을 눌러야 전달됩니다.
