🔐 입실자 이벤트 원장님 모드

가장 간단한 운영 방법: 이벤트를 열 때 설정파일 1개 업로드 → 마감시간에는 홈페이지에서 자동 마감 → 추첨 후 결과파일 1개 업로드입니다.

1. 이벤트 공개 설정

아래 내용을 정한 뒤 이벤트 설정파일 다운로드를 누르세요. 새 이벤트를 시작할 때는 resident-event-config.js와 이전 결과를 지우는 resident-event-result.html이 함께 다운로드됩니다. 두 파일을 GitHub에 덮어쓰면 입실자에게 새 설정만 보이고 이전 추첨 결과는 표시되지 않습니다.

기본은 무작위 추첨입니다. 추천할 때만 1명 또는 2명의 호실을 입력하세요.

※ 응모 초기화를 누르면 resident-event-result.html이 자동 다운로드됩니다. 같은 이름의 파일이 휴대폰 다운로드 폴더에 이미 있으면 브라우저가 자동으로 (1), (2)를 붙일 수 있으므로, 초기화 전에 기존 다운로드 파일을 삭제해 주세요.

3. 마감 · 실제 추첨 · 결과 공개

마감시간이 되면 입실자 화면은 자동으로 응모 마감됩니다. 이후 원장님이 아래 버튼을 눌러 실제 추첨과 결과파일 생성을 진행하면 됩니다.

※ 실제 입실자 응모는 Google Apps Script 서버에 중앙 저장됩니다. 같은 호실은 다른 브라우저·시크릿 모드·다른 휴대폰에서도 두 번 응모할 수 없습니다.
